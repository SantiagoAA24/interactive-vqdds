Dos tarjetas de navegación y explicación. `dd-module` presenta un módulo (etiqueta mono, título, descripción y enlace ámbar). `dd-card` presenta una idea con título ámbar y texto de apoyo.

**Qué aporta quien lo usa:** título, texto y destino del enlace.

- Tarjetas hermanas con la misma altura y el mismo orden interno.
- El enlace de siguiente paso va al pie de la tarjeta.
