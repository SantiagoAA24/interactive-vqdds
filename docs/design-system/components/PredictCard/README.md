Banda de la pregunta guía del patrón Predice. Fondo `band`, radio `radius-3xl`, tres opciones `dd-option` y un bloque `dd-feedback` que aparece al responder.

**Qué aporta quien lo usa:** la pregunta, las opciones, cuál es correcta y el texto de explicación. `data-state="correct"` pinta el borde `success`; `data-state="wrong"` pinta `danger`. El veredicto siempre empieza con una palabra («Correcto.», «No siempre.»), nunca solo con color.
