Superficie para controles, diagramas y resultados. `dd-panel` usa `surface` con borde de 1px `border` y radio `radius-2xl`. `dd-panel--accent` cambia el borde a `accent` y se reserva para el resultado que el estudiante debe mirar (el producto del camino).

**Qué aporta quien lo usa:** el contenido y la separación interna (`space-16` a `space-24` entre bloques).

- Sin sombras: la separación la da el borde.
- No anides paneles; dentro usa filas con `surface-deep`.
