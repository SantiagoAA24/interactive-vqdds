Control deslizante con etiqueta a la izquierda y valor a la derecha en mono ámbar. La etiqueta es un `<label for>` real. `is-violet` se usa para las fases (ω, φ) y el ámbar para el parámetro que reparte probabilidad (r).

**Qué aporta quien lo usa:** `id`, rango, paso y el formateo del valor con coma decimal.

- Siempre muestra el valor numérico.
- Escribe la unidad si la hay (radianes) en una nota debajo.
