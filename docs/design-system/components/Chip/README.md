Botón alternable para elegir un nodo (A, B, C, D) o cambiar un bit (q1 = 1). Estado seleccionado con `aria-pressed="true"`: fondo `surface-selected` y borde `accent`. Sin seleccionar: fondo `bg` y borde `border`.

**Qué aporta quien lo usa:** el estado `aria-pressed` y el manejador de clic. La variante `dd-chip--bit` usa la fuente mono y siempre tiene borde `accent`.

- Muestra el valor actual en la etiqueta del bit.
- Agrúpalos en una fila con `space-12` de separación.
