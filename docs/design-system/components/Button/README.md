Acción principal y secundaria. Usa `dd-btn--primary` (fondo `accent`, texto `on-accent`) para una sola acción por vista, como «Entrenar» o «Empezar con el módulo 1». Usa `dd-btn--secondary` (borde `violet`) para acciones de apoyo. `dd-link` es el enlace ámbar de «siguiente paso» al pie de tarjetas y páginas.

**Qué aporta quien lo usa:** una etiqueta que diga qué ocurre al pulsar, en español y en infinitivo o imperativo corto. El alto mínimo es 48px.

- Una sola acción primaria por bloque.
- No pongas texto blanco sobre `accent`; usa `on-accent`.
- Foco visible: anillo de 3px en `accent` con separación de 3px.
